## 重构主播推流：废弃中继，改用 RTMP（PyAV 优先，ffmpeg 回退）
- 需求：① 改用 RTMP 推流，删除原有中继(TCP socket)上传逻辑；RTMP 服务器地址在代码内固定 127.0.0.1。② 优先用纯 Python（PyAV）采集已选麦克风+摄像头->编码->推流；若 Python 无法推流，回退 ffmpeg。
- 实现要点：
  - 配置区新增 `RTMP_SERVER_IP=127.0.0.1`、`RTMP_PORT=1935`、`RTMP_APP="live"`、`RTMP_STREAM_KEY="zhibodou"`、`RTMP_PUSH_URL`（`rtmp://127.0.0.1:1935/live/zhibodou`），以及码率/预设参数；删除无用中继上传端口常量与 JPEG 编码参数。
  - 新增 `PyAVRtmpPusher`（av 编码 H264/AAC、mux 到 flv 推 RTMP，纯 Python 采集+编码）与 `FFmpegRtmpPusher`（dshow 采集摄像头+麦克风、裁切竖屏+美颜滤镜后推 RTMP）。
  - `_create_pusher()` 自动选后端：`HAVE_AV` 为 True 用 PyAV，否则 `find_ffmpeg()` 找到 ffmpeg 用 FFmpegRtmpPusher，都没有则报错。
  - `find_ffmpeg()` 探测顺序：系统 PATH -> 脚本目录/工作目录下的本地 `ffmpeg(.exe)`（本工程已放 `ffmpeg.exe`，已加入 .gitignore 不入库）-> `imageio-ffmpeg` 自带二进制。
  - `AudioHost` 移除 socket 发送线程，改为把麦克风 PCM 放入推流音频队列；PyAV 后端由本类采集音频，ffmpeg 后端由 ffmpeg 自采音频（Python 端不重复开麦）。
  - `HostStream` 删除全部中继上传方法（`_listen_video_server/_connect_and_send/_video_loop/_check_socket_alive/_listen_audio_server/_connect_audio/_prepare_handshake` 等）；新增 `produce_push_frame()`（美颜->`crop_to_portrait`->缩放 720x1280）、重写 `start_streaming()` 走 RTMP。
  - 主界面新增 RTMP 地址/后端状态标签；`requirements.txt` 增加 `av`、`imageio-ffmpeg`。
